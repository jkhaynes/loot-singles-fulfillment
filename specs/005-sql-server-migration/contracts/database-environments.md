# Database Environment Contract

## Matrix

| Environment | Database | Configuration | Schema | Isolation |
|-------------|----------|---------------|--------|-----------|
| Production | Azure SQL | Deployment-managed identity/configuration | Reviewed migrations | Never shared |
| Manual/hosted development | Azure SQL `loot-singles-dev` | User secret, environment configuration, or managed identity | Reviewed migrations | Never used by automation |
| Integration | SQL Server 2022 Testcontainer | Runtime generated | Migrations per unique database | Unique database per scope |
| Playwright/E2E | SQL Server 2022 Testcontainer | Runtime generated by test host | Migrate then deterministic seed | Dedicated disposable database |
| Unit | None | None | None | Fakes/in-process state only |

## Application configuration

- Required key: `ConnectionStrings:LootSingles`.
- Missing configuration fails startup; invalid identity, firewall, pause, or connectivity fails explicitly.
- No local-file or alternate-provider fallback is permitted.
- Tracked files may document the key, never usable credentials.

## Azure development controls

- Database name `loot-singles-dev`.
- Reverify free-offer eligibility/limits before separately approved provisioning.
- Limit behavior is auto-pause until next month; paid overage disabled.
- Network default deny; allow only required current IPs or scoped private/VNet paths.
- Prefer Entra developer identity locally and managed identity when hosted.
- Broad Azure-services firewall access is not a default.
- This feature contains no provisioning operation.

## Automated-test controls

- Container runtime and pinned image access are prerequisites.
- Tests do not read or require Azure credentials.
- Every database-backed scope applies checked-in migrations before seeding.
- Names are unique and runtime-generated.
- Cleanup disposes contexts/connections, clears pools if required, drops the database, then disposes the container.
- Infrastructure failures provide non-secret diagnostics and fail rather than skip tests.
